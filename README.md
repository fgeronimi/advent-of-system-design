# Advent of System Design

Un calendrier de l’avent pour réviser le system design : 24 concepts, une cassette VHS par jour,
du 1er au 24 décembre. Chaque cassette s’ouvre sur une fiche : le problème, le principe, un schéma,
les compromis, des exemples réels et les questions qu’on te posera en entretien.

## Lancer

Aucune dépendance, aucun build. Ouvre `index.html` ou sers le dossier avec n’importe quel serveur statique :

```sh
npx serve .
```

Les cassettes se débloquent selon la date. Pour tester sans attendre, ajoute `?day=N` à l’URL
(`?day=24` ouvre tout).

## Contribuer

- Le contenu des fiches est dans `concepts.js`.
- Les illustrations des jaquettes suivent le guide de `PROMPTS.md`.
